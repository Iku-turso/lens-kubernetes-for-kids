# Changelog

What changed in each version of this extension, newest first.

## 0.2.0

- Every chapter now has its own animated picture-book illustration: the snowman melts and gets built again, the phone rings, visitors walk to the town gate, and more. Still pictures for anyone whose system asks for reduced motion.
- "Got a question?" on every page: ask Lens's AI helper about what you're reading, and it answers like you're five. Each page keeps its own conversation.
- Bigger chapter icons in the chapter list.
- Fixed the chapter list being squeezed into a thin strip, which hid the chapter names.
- The page is centered, and the "grown-up word" explanation is easier to read in the dark theme.

## 0.1.0

- First release. A storybook tab that explains Kubernetes like you're five, chapter by chapter.
- "Your towns" chapter that describes your own clusters, and counts nodes, pods and namespaces in the connected ones.
- A quiz to finish the story.
- Open it from the top bar, the command palette ("Kubernetes for Kids: Open"), or "Explain like I'm 5" in a cluster's right-click menu.
