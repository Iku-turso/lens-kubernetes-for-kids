# Changelog

What changed in each version of this extension, newest first.

## 0.1.0

- First release. A storybook tab that explains Kubernetes like you're five, chapter by chapter.
- "Your towns" chapter that describes your own clusters, and counts nodes, pods and namespaces in the connected ones.
- A quiz to finish the story.
- Open it from the top bar, the command palette ("Kubernetes for Kids: Open"), or "Explain like I'm 5" in a cluster's right-click menu.
